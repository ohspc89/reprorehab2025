# Week 7: Error Handling & Debugging

## 🧠 What this week is about
This week focuses on understanding and handling Python errors with calm and clarity.
You’ll learn to read, handle, and raise exceptions properly — and use Spyder’s debugger to inspect your code like a pro.

## 🎯 Learning Objectives
After reviewing materials, you'll be able to:
- Recognize common Python error types (`NameError`, `TypeError`, `ValueError`, `KeyError`, `IndexError`, `ZeroDivisionError`)
- Read a traceback **bottom-up** and locate the exact line of failure
- Use `try / except / else / finally` to write safer, more robust code
- Raise your own errors and build simple input-validation checks
- Apply **assertions** for quick sanity checks
- Debug interactively in **Spyder** using breakpoints and the Variable Explorer
