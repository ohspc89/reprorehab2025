# Week 8: Learner demo

This week we invite our learners to introduce how is everyone applying the knowledge gained during bootcamp weeks to their data cleaning / visualizing tasks.

## 🧭 Extra: [Making a notebook using Spyder](https://github.com/ohspc89/reprorehab2025/blob/students/contents/week8/Spyder-notebook.pdf)

By following this setup guide, you will be able to:

### 1. Use Spyder inside a dedicated Conda environment
- Install Miniconda (Windows or macOS)
- Create and activate a separate environment
- Launch Spyder **from inside that environment** so that it uses the correct Python, packages, and settings

### 2. Work with Jupyer Notebooks directly inside Spyder
- Install the **Spyder-Notebook** plugin
- Open `.ipynb` files in Spyder
- Create new notebooks and run code interactively

### 3. Convert notebooks to shareable formats
- Save your notebook as `.ipynb`
- Use `jupyter nbconvert` to create an `.html` version
- Export the HTML to **PDF** for submission or sharing
